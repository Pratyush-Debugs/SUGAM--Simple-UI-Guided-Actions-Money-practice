# SUGAM--Simple-UI-Guided-Actions-Money-practice
Cognitive & Neuro-Inclusive Accessibility Layer (+ Safe UPI Sandbox)
   
​>> Target Beneficiaries: Persons with autism, dyslexia, intellectual disabilities, or cognitive impairments (explicitly recognized under the RPwD Act and      Odisha's BBSA scheme).

​>>The Problem: Almost every accessibility tool focuses on sight or hearing, ignoring cognitive accessibility. Dense text, countdown timers, dark patterns,     and 25-field forms on public portals cause severe cognitive overload and anxiety for neurodivergent users.

​>>The Software Prototype:
​   Cognitive Simplifier Extension: Strips flashing elements and clutter from any portal, converts dense bureaucratic paragraphs into Easy-Read bullet points paired with intuitive pictograms, and breaks 20-field forms into a calm, 1-question-at-a-time wizard.
​Risk-Free Practice Sandbox: Includes a simulated digital payment (UPI) and form-filling training environment with AI guardrails so neurodivergent young adults can practice independent digital transactions without risking real money.
